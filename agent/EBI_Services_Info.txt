10. WEB APPLICATION - COMPLETE GUIDE
====================================================================

The EBI Services platform is a full-stack web application with THREE
main components:
- A public website (Home, Services, About, Contact pages)
- A Client Portal (for registered clients)
- An Admin CRM Dashboard (for EBI staff)

--- 10.1 PUBLIC PAGES (no login required) ---

HOME PAGE (/):
- Company presentation with stats and testimonials
- Buttons: "Schedule Consultation" -> goes to Contact page
           "Become Portal Client" -> goes to Registration page
           "Talk with AI" -> opens this chatbot
           "Explore Our Workflows" -> goes to Services page

SERVICES PAGE (/services):
Three department tabs with detailed information:
1. Software Development (React, TypeScript, ERP, Agile sprints)
2. IT Recruitment & HR (Talent sourcing, vetting pipeline)
3. Tele-Services & Support (Call center 24/7, back-office)
- Button: "Book Consultation Meeting" -> goes to Contact page
- Button: "Submit Quote Request" -> requires login, goes to Portal

ABOUT PAGE (/about):
- Company overview, core pillars, CEO vision

CONTACT PAGE (/contact):
- Contact form: Name, Email, Phone, Description of need
- Submission creates a ticket and sends confirmation email
- Phone: +33 1 74 88 99 00
- Address: 12 Avenue des Champs-Elysees, Paris
- Hours: 08:30 AM - 06:30 PM (CET), Mon-Fri
- FAQ section with 4 common questions

--- 10.2 REGISTRATION & LOGIN ---

REGISTRATION (/register):
- Fields: Full Name, Company (optional), Email, Password
- On success: account created, redirected to login
- After login: client goes to Client Portal

LOGIN (/login):
- Fields: Email, Password
- Admin users -> Admin CRM Dashboard
- Client users -> Client Portal
- "Forgot Password?" -> enter email -> receives reset link

PASSWORD RESET (/reset-password):
- Accessed via email link with token
- Enter new password (min 6 characters)

--- 10.3 CLIENT PORTAL (requires login as client) ---

The Client Portal has 5 sub-sections:

A) OVERVIEW (Dashboard):
- Stats: Total Request Pipelines, Issued Quotations, Scheduled Meetings
- Lists your quotations and notifications

B) QUOTATIONS & REQUESTS:
- Left panel: "My Scoping Requests" - all your quote requests with statuses
- Right panel: "Issued Proposals" - formal quotes from EBI with Accept/Reject buttons

Quote workflow:
1. Click "Request Quote" button (top of portal)
2. Fill: Industry, Project Category, Budget, Deadline, Requirements, optional RFP file
3. Submit -> status "new"
4. EBI reviews -> issues formal quote -> status "quoted"
5. You see quote with pricing and terms
6. Click "Accept & Sign SLA" or "Reject Quote"

C) CONSULTATIONS (Appointments):
- Lists all your appointments with date, time, status
- "Cancel Appointment" button for pending ones

Booking workflow:
1. Click "Book Consultation" button (top of portal)
2. Fill: Meeting Objective, Date, Time Slot (09:00-10:00, 10:00-11:00, etc.), Timezone
3. Submit -> status "pending"
4. EBI confirms -> status "confirmed"
5. You receive notification

D) MANAGER CHAT:
- Direct messaging with EBI department heads
- Type and send messages, see conversation history

E) SECURE VAULT (Documents):
- Drag-and-drop file upload (PDF, Word, Excel, Images, max 10MB)
- View, download, and delete uploaded documents

--- 10.4 ADMIN CRM DASHBOARD (requires admin login) ---

A) CRM ANALYTICS:
- Stats: Total Leads, Active Clients, SLA Conversion %, Revenue
- Charts: Performance over time, Leads by department

B) MANAGE LEADS:
- Search and filter leads by department/status
- Update lead status (new -> contacted -> qualified -> lost)
- Add/edit CRM notes
- Export leads as CSV

C) QUOTE PROPOSALS:
- View incoming quote requests from clients
- Click "Generate Formal Quote" -> enter pricing and terms
- Issue formal quote -> client gets notified

D) APPOINTMENTS BOARD:
- View all appointments
- Confirm or decline pending bookings
- Add admin notes

E) SYSTEM CONFIGS:
- Edit website name, chatbot prompt, welcome message, email templates

F) AUDIT LOGS:
- View all activity logs
